Đây là chính website bạn đang xem: nơi mình trưng bày dự án, viết blog và ghi chép lộ trình học Cấu trúc dữ liệu & Giải thuật.

## Tính năng chính

- **Trang tĩnh 100%** dựng bằng Astro, tải nhanh, deploy tự động lên GitHub Pages qua GitHub Actions mỗi lần push lên `main`.
- **Quản trị nội dung bằng Decap CMS** tại `/admin`: viết bài, thêm ghi chú, dự án và chứng chỉ mà không cần sửa code.
- **Blog & Ghi chú viết bằng MDX**: nhúng được React component (`<Callout>`), công thức toán bằng KaTeX.
- **Sổ tay ghi chú** (DSA, Design Pattern...) chia theo chủ đề và cấp độ (Cơ bản → Chuyên sâu), có tag để lọc nhanh.
- **Góc học tập** `/learn`: lộ trình theo thể loại → session → bài học, có quiz.
- **Lab / Playground**: chạy thử code JS, Python, Rust ngay trên trình duyệt (WebAssembly) và vài mini game.
- **PWA**: cài được như app, có service worker để cache.
- **Tìm kiếm toàn site** bằng Pagefind (chạy hoàn toàn phía trình duyệt, không cần server).
- **SEO**: sitemap, RSS feed, thẻ Open Graph để chia sẻ lên mạng xã hội đẹp hơn.
