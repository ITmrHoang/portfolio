# 📚 Tài Nguyên Tham Khảo Rust hữu ích

### 🔗 Link Học Tập Chính Thức:
- **The Rust Programming Language (The Book):** [doc.rust-lang.org/book/](https://doc.rust-lang.org/book/)
- **Rust by Example:** [doc.rust-lang.org/rust-by-example/](https://doc.rust-lang.org/rust-by-example/)
- **Cargo Package Registry:** [crates.io](https://crates.io)

### 📦 Các Crate Phổ Biến Cần Biết:
* `serde`: Serialization / Deserialization dữ liệu JSON.
* `tokio`: Async Runtime dành cho ứng dụng bất đồng bộ.
* `reqwest`: HTTP Client siêu nhanh.
* `clap`: Xây dựng CLI argument parser mạnh mẽ.
