# 🦀 Chào mừng bạn đến với Rust!

**Rust** là ngôn ngữ lập trình hệ thống tập trung vào **hiệu năng (performance)**, **an toàn bộ nhớ (memory safety)** và **tính song song (concurrency)** mà không cần Garbage Collector (trình thu gom rác).

## 💡 Các tính năng nổi bật của Rust:
1. **Ownership (Quyền sở hữu):** Quản lý bộ nhớ an toàn ngay tại thời điểm biên dịch (Compile-time).
2. **Zero-cost Abstractions:** Không tốn chi phí hiệu năng cho các trừu tượng hóa cao cấp.
3. **Thread Safety:** Ngăn chặn data race khi lập trình đa luồng.

```rust
fn main() {
    let message = "Hello, Rustacean!";
    println!("{}", message);
}
```
