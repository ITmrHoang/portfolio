## 1. Các Tính Năng Nổi Bật Của Popup Sider

<Callout title="Kiến trúc thiết kế linh hoạt" type="info">
- **Chế độ Ghim (Pin Sider)**: Ghim bảng điều khiển cố định bên phải màn hình hoặc mở dạng Modal Overlay.
- **Bảng Mô Tả Bên Trái (Left Panel)**: Cho phép ẩn/hướng dẫn bài tập, option cấu hình hoặc thu gọn 100% để tập trung viết code.
- **Đa Ngôn Ngữ Trực Tiếp**:
  - **JavaScript / TypeScript**: Chạy cách ly trực tiếp qua JS Sandbox Runtime.
  - **Python**: Tích hợp Pyodide WebAssembly (chạy Python 3.11 trực tiếp trong trình duyệt).
  - **Rust**: Gửi mã nguồn biên dịch tới **Rust Playground Server API** và hiển thị kết quả log compilation & stdout.
  - **HTML / CSS / Live UI**: Live preview giao diện trực quan trong iframe độc lập.
  - **SQL**: Thực thi truy vấn SQLite trực tiếp qua WebAssembly.
- **Bộ Kiểm Thử & Debug Logs**: Tùy chọn thu gọn / mở rộng bảng Console Output và Test Cases với trạng thái Passed/Failed và thời gian thực thi (ms).
</Callout>

function twoSum(nums, target) {
  const map = new Map();
  for (let i = 0; i < nums.length; i++) {
    const diff = target - nums[i];
    if (map.has(diff)) {
      return [map.get(diff), i];
    }
    map.set(nums[i], i);
  }
  return [];
}
