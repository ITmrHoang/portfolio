# UV Guide - Python Package & Version Manager

## UV là gì?

UV là công cụ của Astral thay thế:

- pip
- pip-tools
- virtualenv
- venv
- pyenv (một phần)

UV viết bằng Rust nên nhanh hơn pip rất nhiều.

---

# Cài đặt UV

## Windows

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Linux / Mac

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Kiểm tra:

```bash
uv --version
```

---

# Quản lý Python Version

## Xem các bản Python khả dụng

```bash
uv python list
```

Ví dụ:

```text
Python gốc là cpython viết bằng C
cpython-3.13.7 
cpython-3.12.11
cpython-3.11.13

pypy là python kết hợp JTT
pypy-3.11-v7.3.20
```

---

## Cài Python

trong windown sau khi cài python các phiên bản sẽ trong folder, có thể vào để cài env PYTHON tương ứng để các path sử dụng
```
%AppData%\Roaming\uv\python
```

### Cài Python 3.13

```bash
uv python install 3.13
```

### Cài Python 3.12

```bash
uv python install 3.12
```

### Cài PyPy

```bash
uv python install pypy
```

---

## Xem các Python đã cài

```bash
uv python list --only-installed
```

# Chuyển đổi Python Version

## Pin version cho project

```bash
uv python pin 3.12
```

Tạo file:

```text
.python-version
```

Ví dụ:

```text
3.12
```

---

## Đổi sang Python khác

```bash
uv python pin 3.13
```

---

## Kiểm tra Python đang dùng

```bash
uv run python --version
```

# Package Management

## Thêm package

```bash
uv add requests
```

```bash
uv add fastapi
```

```bash
uv add pandas
```

Nó sẽ update:

```text
pyproject.toml
uv.lock
```

---

## Thêm nhiều package

```bash
uv add fastapi uvicorn sqlalchemy
```

---

## Package Dev

```bash
uv add --dev pytest
```

```bash
uv add --dev black
```

```bash
uv add --dev ruff
```

---

## Xóa package

```bash
uv remove requests
```

---

## Update package

```bash
uv lock --upgrade
```

# Chạy chương trình

## Chạy file

```bash

```

---

## Chạy module

```bash

```

---

## Chạy với version cụ thể

```bash

```

```bash

```

# Đồng bộ môi trường

Khi clone project:

```bash
git clone <repo>
cd project
```

Cài toàn bộ dependency:

```bash
uv sync
```

UV sẽ:

- đọc pyproject.toml
- đọc uv.lock
- cài đúng version package
